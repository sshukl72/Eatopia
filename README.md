What is CDN? Why do we use it?

CDN is content delivery network.CDN (Content Delivery Network) is a network of servers that deliver web content efficiently, reducing load times for users globally.CDNs are used to improve web performance and reduce latency, or the delay in communication between a website and a user.

What is CrossOrigin in CDN link?

CrossOrigin is the mechanism that allows web apps to access resources from different domain using header. It is the type of http protocol.

Why is React known as React?
React is named after its ability to "react" to changes in a user's actions without reloading the entire page.

What is diference between React and ReactDOM?
React
A library for building user interfaces. React is used to create components, classes, and elements. It's designed to handle complexity and converts React elements to DOM elements during rendering.
ReactDOM
A library that connects React to the browser's Document Object Model (DOM). It's used to render React elements in the browser and manipulate the DOM. ReactDOM provides methods like render() and findDOMNode().

what is Emmet?
Emmet is a free, open-source set of plugins that helps web developers write HTML and CSS code faster. It was previously known as Zencoding.

Difference between a Library and Framework?
The main difference between a library and a framework is that a library gives developers control over the application flow, while a framework controls the flow. This is known as the inversion of control.
